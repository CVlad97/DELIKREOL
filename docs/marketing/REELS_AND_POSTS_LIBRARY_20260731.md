# Bibliothèque publications, stories et Reels DELIKREOL

## Reels 15 secondes

### Reel 1 — Commande simple
- 0–3s : “Tu cherches un plat local aujourd’hui ?”
- 3–7s : capture catalogue + ajout panier.
- 7–11s : écran WhatsApp avec numéro de commande.
- 11–15s : “DeliKreol — commande local, confirme WhatsApp.”
- CTA : “Va sur delikreol.com”.

### Reel 2 — Traiteur partenaire
- 0–4s : portrait traiteur + logo.
- 4–9s : 3 plats HD.
- 9–12s : “Menu, visibilité, demandes qualifiées”.
- 12–15s : “Deviens partenaire DeliKreol”.

### Reel 3 — Business
- 0–4s : “Réunion demain ?”
- 4–9s : plateau repas / traiteurs locaux.
- 9–12s : “Devis + livraison planifiée”.
- 12–15s : “DeliKreol Business”.

## Règles visuelles

- Jamais de photo floue.
- Jamais de vignette saturée ou étirée.
- Toujours logo + nom partenaire + prix clair.
- Format Feed : 1080×1080.
- Format Story/Reel : 1080×1920.
- Texte maximal sur visuel : 8 mots.
