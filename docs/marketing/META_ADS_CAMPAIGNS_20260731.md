# Campagnes Meta Ads DELIKREOL — plan prêt à saisir

## Pré-requis non négociables

- Page Facebook officielle créée.
- Compte Instagram professionnel relié.
- WhatsApp Business relié à la Page.
- Pixel Meta installé uniquement avec `VITE_FB_PIXEL_ID` public, sans token secret frontend.
- Aucun scraping Instagram/Facebook : utiliser Meta Business Suite, API officielle ou publication manuelle.

## Campagne 1 — Clients locaux WhatsApp

- Objectif : messages WhatsApp.
- Audience : Martinique, 18–55+, intérêts cuisine créole, repas, livraison, événements, marché local.
- Budget test : 10–15 €/jour pendant 7 jours.
- CTA : `Envoyer un message WhatsApp`.
- Angle : “Repas créoles locaux, commande simple, confirmation WhatsApp”.
- Asset : `/marketing/ads/delikreol-b2c-whatsapp.svg`.

Copies :
1. “Envie d’un vrai repas local sans chercher partout ? DeliKreol prépare ta demande et confirme sur WhatsApp.”
2. “Traiteurs martiniquais, plats créoles, retrait ou livraison planifiée. Commande local sur DeliKreol.”

## Campagne 2 — B2B repas d’équipe

- Objectif : leads ou messages WhatsApp.
- Audience : Martinique, responsables RH, dirigeants PME, administrations, associations, événementiel.
- Budget test : 15–25 €/jour.
- CTA : `Demander un devis`.
- Landing : `https://delikreol.com/business`.
- Asset : `/marketing/ads/delikreol-business-livraison.svg`.

Copies :
1. “Réunion, séminaire, équipe terrain : organisez un repas créole livré sur devis.”
2. “Un seul contact, plusieurs traiteurs locaux, confirmation WhatsApp et facture préparée.”

## Campagne 3 — Recrutement traiteurs

- Objectif : prospects partenaires.
- Audience : Martinique, entrepreneurs, restauration, cuisine, pâtisserie, traiteur, food truck.
- Budget test : 8–12 €/jour.
- Landing : `https://delikreol.com/devenir-partenaire`.
- Asset : `/marketing/ads/delikreol-traiteurs-recrutement.svg`.

Copie : “Traiteurs de Martinique : gagnez en visibilité sans gérer un site. DeliKreol vous aide à recevoir des demandes qualifiées.”

## Campagne 4 — Recrutement livreurs / relais

- Objectif : formulaire ou WhatsApp.
- Audience : Martinique, 18–45, mobilité, livraison, auto-entrepreneur.
- Budget test : 5–10 €/jour.
- Landing : `https://delikreol.com/recrutement`.

Copie : “Rejoignez le réseau local DeliKreol : livraisons planifiées, points relais et partenaires de proximité.”

## Événements conversion à suivre
